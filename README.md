# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、按甲机/乙机排片、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

## 双机排片与片门清洁

- 录入或修改片段时选择**甲机**或**乙机**，系统按机器分别累计放映时长，机位状态条实时显示本轮累计（90 分钟进度）。
- 某台机器本轮累计达到 **90 分钟**后，下一段开始前必须在「片门清洁」面板**登记清洁人和清洁时间**；未登记时该段标记为「待清洁·不能开始」，后续片段顺延等待。
- 登记清洁后该机器累计清零、继续放映；清洁记录按时间顺序逐次消耗，记录列表会标注「已生效 / 待使用」。
- 替换片段、修改时长、换机或拖动顺序时，**只重算受影响机器**的状态，另一台机器沿用缓存结果继续放映（机位卡片上的「状态更新于」时间可印证）。

## 数据存储

三类数据分开保存在不同的 localStorage 键下，互不影响：

| 内容 | 键 |
| --- | --- |
| 清单（胶片卷与片段） | `zfl17-film-strip-desk` |
| 清洁记录 | `zfl17-film-strip-desk-cleanings` |
| 页面操作（筛选、搜索、默认机位） | `zfl17-film-strip-desk-ui` |

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
